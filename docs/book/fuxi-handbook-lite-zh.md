# 第一章 为什么需要这个框架

## 1.1 三重不对称：这个时代的学习困境

**知识在膨胀**：科学文献以年复合约 +4.1% 的速度增长、约 17.3 年翻一番（战争后阶段更快）[C203]；全球存储容量 1986–2007 年间以约 +23%/年增长 [C204]。没有任何人的学习带宽在同步变宽——「读完再上场」的策略已经破产。

**教育在滞后**：2022 年 PISA 显示多国数学与阅读出现历史性下滑 [C209]；中低收入国家约 70% 的 10 岁儿童读不懂简单短文 [C206]；大规模开放在线课程的证书完成率长期停留在约 3% 的量级 [C205]——「开放」不等于「完成」。

**AI 是双刃剑**：无护栏使用生成式 AI，练习期表现 +48%、撤掉后考试 −17% [C56]；而带护栏的 AI 导师实验让学习显著提速 [C59]。差别不在 AI，而在使用协议。

![图 1 · 知识缺口与三重时代危机](../assets/fuxi-why.svg)

## 1.2 四个论点（深度剖析入口）

1. **方法碎片化**：每个技巧都带条件、剂量与顺序，剥掉这些只剩口号；解药是框架层认知。
2. **伪科学横行**：学习金字塔、学习风格匹配、速读等六大神话仍在传播；真正高效的方法（检索练习、间隔重复）反而被冷落 [C05][C214][C215]。
3. **爽感陷阱**：重读、划线、看视频让人「感觉在学」，延迟测验一做就露馅——流畅感是骗子 [C01][C220]。
4. **AI 时代的新风险**：认知卸载、幻觉、自动化偏误、评价失效、认知分层——必须内建护栏 [C56][C222][C224]。

## 1.3 设计四原则

**地图优先**（十阶时间线回答「何时用哪个」）· **证据分级**（每个方法标 A/B/C/D）· **AI 有护栏**（独立尝试 → 质询找错 → 脱稿复现）· **开源可纠错**（全部内容 CC BY 4.0，错误公开修正）。

## 2.2 每阶一卡

① **立志**：把「想学 X」写成可验证目标 + 期限 + 每周时段；用「如果〈情境〉，就〈动作〉」把计划挂到固定线索上。过关：能一句话说明「学成什么样算成功」。

② **建图**：用发展史、对比或顶点倒推任一进路，画出一页领域地图，标出 5–9 个组块与前置关系。过关：能不看资料讲出领域骨架。

③ **拆解**：把技能拆成 15–60 分钟可练的原子动作，按依赖排序。过关：清单上每一项都能在一小时内完成一次完整练习。

④ **编码**：对每个新概念写「最简解释」（用自己话讲给别人），主动问「为什么/怎么不同」，先自己写再对照。过关：能给外行讲懂 3 个核心概念。

⑤ **检索**：学完立即合上材料回忆、对照补缺；卡片一题一面。过关：当天内容通过「空白纸回忆」测试。

⑥ **间隔**：把复习时点交给调度算法（如 FSRS），在快忘记时复习；考前分散到多天。过关：连续 2 周按计划复习，完成率 > 80%。

⑦ **精练**：针对弱点设计练习：子目标 + 能力边缘 + 即时反馈 + 修正；混合题型练。过关：弱项在延迟测试中提升可观察。

⑧ **应用**：做真实项目，「做 → 卡 → 定向查学 → 回填」循环。过关：产出一个可展示的作品或交付物。

⑨ **教学**：脱稿讲给别人（或录音自讲），卡壳处即漏洞；同伴讨论前先各自作答。过关：完成一次 ≥10 分钟的脱稿讲解。

⑩ **维护**：固定线索 + 最小启动动作养成习惯；睡眠 7–9 小时规律、每周 150 分钟运动。过关：连续 4 周系统未断链。

⑪ **拓界**：走到人类知识边界后，用科研方法（无知清单、证伪优先）与五大赛道（科研/创业/人际/长寿/未来）继续创造。过关：提出一个可检验的新问题。

# 第三章 八张方法卡（先学这八个）

**① 检索练习（A）**：合上材料写/说出全部能回忆的内容，再对照补缺。原理：提取本身会加固记忆 [C01]。常见错用：只重读不复述、只翻卡片不回忆。

**② 间隔重复（A）**：把复习交给调度算法（FSRS），间隔随记忆强度扩展；目标保持越久、间隔越长 [C04]。常见错用：每天固定复习全部、临时抱佛脚。

**③ 自我解释（A）**：学每一步时自问「为什么成立」并写下答案 [C19]。常见错用：只看不想，把「看懂」当「学会」。

**④ 生成效应（A）**：先自己写出答案再看解析，让大脑先「生成」再校对 [C02]。常见错用：先看答案再假装自己也会。

**⑤ 刻意练习（B）**：明确子目标 + 在能力边缘 + 即时反馈 + 重复修正；领域不同效应不同（教育领域约 4% 方差）[C32]。常见错用：舒适区重复、无反馈硬练。

**⑥ 合意困难（B）**：让提取「稍微费力」——拉长间隔、交错题型、减少提示；困难必须服务于检索与区辨 [C219]。常见错用：把任何痛苦都当有效。

**⑦ 迁移设计（B）**：练习覆盖变式与跨情境；近迁移易、远迁移难，需要刻意设计 [C244]。常见错用：同一题型刷到熟，换个场景就废。

**⑧ AI 护栏三协议（强制）**：先独立尝试（哪怕错）→ 再让 AI 质询/找错/出题 → 最后脱稿复现才算学会 [C56][C59]。常见错用：直接要答案、把 AI 当代笔。

# 第四章 拓界篇：知识边界之后

科研不是终点而是起点：当你把「无知清单」写得足够具体，课题自会浮现。五个方向共用同一条创造循环——无知 → 问题 → 实验 → 证据 → 创造 → 传播。

![图 3 · 拓界循环整合图](../assets/fuxi-integration.svg)

**科研**：从「无知清单」到「四矿脉」（争议/断裂/工具/迁移）找真问题；证伪优先于证实。

**创业**：用 RCT 级证据的方法论——Mom Test 访谈（只问过去行为）→ 可证伪的 MVP → PMF（留存曲线走平）→ 渠道与护城河；创始人平均年龄 40+，「年轻才行」是幸存者偏差 [C125]。

**人际**：四类经典模型（成人依恋 / 爱情三角 / 强弱连接 / 互惠博弈）；末日四骑士预测关系解体，修复尝试是关键变量 [C135]；社会连接与存活率 +50% 量级 [C136]。

**长寿**：衰老有十二大标志 [C138]；把筹码押在 A 级因素：不吸烟、运动（死亡风险 −30~40% [C139]）、睡眠 7–9 小时、地中海饮食（PREDIMED RCT [C141]）、社交连接。补剂与换血疗法证据等级 C/D——别做。

**未来**：先学「怎么判断预测」（超级预测：分层校准 + 基础率 + 频繁更新 [C151]）；六大前沿科学雷达（AI / 生物 / 聚变 / 健康老龄化 / 气候 / 空间）；宏观趋势：人口 2080 年代达峰约 103 亿 [C147]、每 +0.5°C 风险上台阶 [C148]、竞争性共存 [C149]。
