# 第 5 阶 · 检索（Retrieve）<br/><sub>巩固纪 · 合上书，从脑中取出来</sub>

[上一阶 ←](./04-encode.md)

> 建议占时：持续（随学随测，成为日常动作）｜ 证据总评：A 为主 ｜ 上一阶：[编码](./04-encode.md) ｜ 下一阶：[间隔](./06-space.md)

## 阶段目标

- 把「复习」变成「考试」：空白纸回忆 + 自出题 + 低风险测验成为每天的默认动作。
- 任一主链主题，空白纸回忆覆盖 ≥ 80% 要点。
- 延迟 48 小时复测，成绩仍 ≥ 70%。
- 错误卡片全部带「为什么错」备注；每周有一份可追溯的测验记录。

## 为什么放在这里（认知机制）

检索位于巩固纪之首：编码把内容连接成网，检索负责证明它还在不在。对照实验中，一周后重复检索组的回忆率约 80%，重复学习组只有约 35%（[C01]）；测验相比重复阅读更利于长期保持（[C02]），这一方向在练习测验的系统元分析中依然稳健（[C03]）。机制上，提取本身会强化记忆痕迹——费力但可成功的「合意困难」最有利于长期保留（[C66]）；检索后立即对照反馈，决定错误能否被纠正（[C46][C47]）。反过来，重读与划线带来的流畅感只是当下的熟悉（[C05]）；学会没有，只能用延迟的取出来验证。

## 核心方法（方法卡）

*等级为本项目对现有证据的综合判断，非期刊官方评级。*

### 检索练习与测试效应（Retrieval Practice / Testing Effect）

- **机制**：从记忆中主动提取会强化痕迹，比重复输入更耐久；提取越费力（在能成功的范围内），收益越大。
- **怎么做**：
  - 学完一组内容后合上材料，自问自答；答不出再看，看完立即再答一遍。
  - 每张卡跑「问题 → 自答 → 核对 → 改错」四步循环。
  - 自出题优先于复用现成题库：出题本身就是加工。
  - 复测安排在 48 小时后，而不是当天反复重来。
- **最合适**：几乎所有可陈述的知识；**不适用**：完全陌生领域的第一遍接触——先完成第 4 阶编码。
- **证据**：A + [C01][C02][C03]（<https://doi.org/10.1126/science.1152408>；<https://journals.sagepub.com/doi/10.1111/j.1745-6916.2006.00012.x>；<https://gwern.net/doc/psychology/spaced-repetition/2017-adesope.pdf>）

### 自由回忆（Free Recall／Blank Page）

- **机制**：无提示写下记得的全部，暴露真实提取范围与结构缺口；比再认（看到能认出）严格得多。
- **怎么做**：
  - 限时 5 分钟，围绕一个主题在空白纸/白板上写下所有要点与关系。
  - 对照材料，用另一色标出：写对 / 写错 / 漏掉。
  - 漏点补卡，错点写「为什么错」。
  - 隔日再做同一张空白纸，比较覆盖率变化。
- **最合适**：主题收尾、考前盘点；**不适用**：从未编码过的内容——先编码，收益才成立。
- **证据**：A + [C01]（<https://doi.org/10.1126/science.1152408>）

### 自建卡片（Generating Your Own Cards）

- **机制**：出题需要判断「什么值得考、答案边界在哪」，本身就是深度加工；现成卡组省事，但省掉了这一层。
- **怎么做**：
  - 从空白纸回忆的漏点、错点出发出题，不逐句抄教材。
  - 一卡一问；答案写成最小完整句，附 1 个例子或反例。
  - 优先「为什么」类问题；数字与定义保留原始口径。
  - 出完先自测一遍，删掉「不用想就会」的卡。
- **最合适**：理解之后的巩固；**不适用**：冲刺最初几天可先用优质现成卡组起步，但两周内过渡到自建。
- **证据**：A + [C01][C05]（<https://doi.org/10.1126/science.1152408>；<https://pubmed.ncbi.nlm.nih.gov/26173288/>）

### 预测试（Pretesting）

- **机制**：先猜后学——即使猜错，也激活注意与缺口感，让后续学习有的放矢；猜测加反馈能留下纠错痕迹。
- **怎么做**：
  - 学新课前，凭猜测先回答 3–5 个问题。
  - 学完后回答同一批问题，对照前后差异。
  - 保持低风险：不计分、允许错、以找缺口为目的。
  - 直接用第 2 阶地图上的主干问题当题库。
- **最合适**：新章节启动、前概念排查；**不适用**：完全零基础时先给提示或骨架，避免纯猜变成乱编。
- **证据**：B（对照研究支持，受情境调节）

### 校准训练（Calibration）

- **机制**：「感觉会了」不可靠——学习判断常被流畅感误导；先预测、后实测，用偏差校正自我评估。
- **怎么做**：
  - 复习前预测这批卡能过多少，写下数字。
  - 实测后对比预测与实际，记录偏差方向（过度自信还是低估）。
  - 难度分级靠小测，不靠感觉。
  - 每周看一次偏差趋势，调整测验频率与内容。
- **最合适**：冲刺期排计划、判断复习优先级；**不适用**：低风险探索期可轻量跳过。
- **证据**：B + [C05][C50]（[C05] <https://pubmed.ncbi.nlm.nih.gov/26173288/>；[C50] 文本引）

### 反馈修正（Feedback Correction）

- **机制**：检索后的即时核对决定错误能否被纠正；无反馈的重复可能固化错误，而反馈形式高度影响效果。
- **怎么做**：
  - 每次检索后立刻核对答案，错题当场改，不隔夜。
  - 错题备注写清「为什么错」：概念混淆 / 步骤缺失 / 记忆缺失 / 粗心。
  - 反复错的卡改写提问角度、拆小、加例子。
  - 修正后 48 小时复测，确认纠正生效。
- **最合适**：所有检索场景；**不适用**：暂无例外——拿不到答案时先标记「待核对」，随后补齐。
- **证据**：A + [C46][C47]（<https://doi.org/10.3102/003465430298487>；<https://psycnet.apa.org/record/1996-02773-003>）；[C47] 另有提醒：约 1/3 以上的反馈干预反而降低表现——反馈要具体、对事不对人。

## 过关自测

- 任一主链主题：空白纸回忆覆盖 ≥ 80% 要点（第一遍）。
- 延迟 48 小时后复测，仍 ≥ 70%。
- 错误卡片有「为什么错」备注，且补充了修正动作。
- 预测-实际偏差有记录，连续两周偏差在收窄。
- 每天有一轮「先合书、再核对」的检索动作可查。

## 常见误区

- 重读、划线自我安慰：低效用证据一致（[C05]）；复习必须以「先合书」开头。
- 只做选择题：再认远比简答容易，会高估水平；主链主题用简答或空白纸（[C01]）。
- 没做延迟测验就宣布「学会了」：当天流畅不可信，放到 48 小时后再说（[C01][C50]）。
- 拿画图代替检索：对迁移测验，检索练习优于概念图复习（[C71]）；图是编码工具（第 4 阶），不是复习的替代品。

## AI 副驾（此阶段）

- 先考后判：让 AI 当考官，你先作答、它再判分并追问；模式设成「不许给答案，只提问」。练习期直接依赖 AI 给答案，撤除后成绩会掉（[C56]）。
- 变式题生成：用 AI 批量出变式题（换情境、换数字、换问法），先人工抽检几道确认没跑偏，再拿来自测。
- 防依赖：AI 判错的题以你的核对为准；每两周安排一个「无 AI 日」，独立完成空白纸与延迟测验（依赖与元认知懒惰风险见 [C57]；另见一项未同行评审的预印本研究提示的关联风险（[C58]））。
