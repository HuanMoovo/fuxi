# 人生时间线 · 学习友链目录 Lifespan Learning Directory

> 按**人生阶段**排序的学习友链：从出生到老年，每个阶段 = 学习重点 × 最值得的开源工具 × 对应十阶。全部条目经 GitHub API 核验（2026-10-03），可点击、可加载。
>
> 姊妹篇：分类版 [学习友链目录](./awesome-learning.md)（2464 条）。年龄分段是启发式参考，不是硬性规定 —— 成年后决定学习的不是年龄，而是「目标 × 领域 × 资源」。

> 本目录由 [`generator/build_lifespan.py`](https://github.com/HuanMoovo/fuxi/blob/main/generator/build_lifespan.py) 可复现生成。


## 0–3 岁 ｜ 婴幼儿期

> 重点：真人对话、亲子共读、自由玩耍；让语言输入又多又暖。

**此阶段几乎没有值得推荐的开源软件 —— 最好的「工具」是照护者本人。** 若一定要看，可把屏幕交给「听」而不是「看」。


对应十阶：地基未开始（可先读 [第 1 阶 · 立志](./stages/01-orient.md) 的「环境设计」一节）


## 3–6 岁 ｜ 幼儿期

> 重点：玩中学、前读写与数感、规则类游戏。

屏幕时间受控（WHO 建议 3-4 岁 ≤1 小时/天，越少越好），优先亲子共玩。


对应十阶：→ [② 建图](./stages/02-map.md) · [④ 编码](./stages/04-encode.md)（以游戏与实物为主）

- **[GCompris](https://github.com/KDE/gcompris)** ★59 — 2-10 岁互动益智活动合集（离线）
- **[Sugar](https://github.com/sugarlabs/sugar)** ★313 — OLPC 儿童学习桌面环境
- **[Kolibri](https://github.com/learningequality/kolibri)** ★1.1k — 离线 K-12 课程库（低带宽地区广泛使用）

## 6–12 岁 ｜ 儿童期

> 重点：读写算打底、好奇心保护、第一次「做成一个项目」。

编程启蒙与汉字书写都可以从图形化 / 动画化工具开始。


对应十阶：→ [③ 拆解](./stages/03-decompose.md) · [⑦ 精练](./stages/07-drill.md)

- **[Blockly](https://github.com/RaspberryPiFoundation/blockly)** ★1.4万 — 积木式编程（教学标准件）
- **[Scratch GUI](https://github.com/scratchfoundation/scratch-gui)** ★4.8k — Scratch 图形化编程（作品社区）
- **[Code.org](https://github.com/code-dot-org/code-dot-org)** ★900 — K-12 计算机科学课程平台
- **[Hanzi Writer](https://github.com/chanind/hanzi-writer)** ★5.0k — 汉字笔顺动画练习

## 12–18 岁 ｜ 少年期

> 重点：学习方法升级（检索练习/间隔重复）、编程与学科入门、第一次公开作品。

此阶段最大的杠杆是「学习方法的更换」，而不是刷更多题。


对应十阶：→ [⑤ 检索](./stages/05-retrieve.md) · [⑥ 间隔](./stages/06-space.md)

- **[Hello 算法](https://github.com/krahets/hello-algo)** ★13.1万 — 动画图解数据结构与算法（中文）
- **[freeCodeCamp](https://github.com/freeCodeCamp/freeCodeCamp)** ★45.7万 — 免费交互式编程课程
- **[Python-100-Days](https://github.com/jackfrued/Python-100-Days)** ★18.7万 — Python 百日成体系教程（中文）
- **[The Odin Project](https://github.com/TheOdinProject/theodinproject)** ★4.6k — 项目式全栈 Web 课程
- **[3Blue1Brown 视频源码](https://github.com/3b1b/videos)** ★1.1万 — 数学可视化视频（配 Manim 复现）
- **[Manim](https://github.com/ManimCommunity/manim)** ★4.1万 — 复现/创作数学动画
- **[代码随想录](https://github.com/youngyangyang04/leetcode-master)** ★6.3万 — 刷题顺序与题解体系（中文）

## 18–25 岁 ｜ 青年期

> 重点：系统化学科训练、向「专业」的第一跳、建立自己的知识库。

大学的核心竞争力不是课表，而是「自学引擎 + 检索/间隔系统」。


对应十阶：→ [② 建图](./stages/02-map.md) · [⑦ 精练](./stages/07-drill.md) · [⑧ 实战](./stages/08-apply.md)

- **[cs-self-learning](https://github.com/PKUFlyingPig/cs-self-learning)** ★7.6万 — 计算机自学指南（中文）
- **[OSSU](https://github.com/ossu/computer-science)** ★21.0万 — 开源自修计算机学位
- **[The Missing Semester](https://github.com/missing-semester/missing-semester)** ★6.1k — MIT：工具链与命令行
- **[CS-Notes](https://github.com/CyC2018/CS-Notes)** ★18.6万 — 技术面试知识笔记
- **[d2l-zh](https://github.com/d2l-ai/d2l-zh)** ★8.1万 — 《动手学深度学习》（中文）
- **[nn-zero-to-hero](https://github.com/karpathy/nn-zero-to-hero)** ★2.5万 — 从零手搓神经网络
- **[Anki](https://github.com/ankitects/anki)** ★3.2万 — 间隔重复系统（大学四年最划算的工具）
- **[FSRS4Anki](https://github.com/open-spaced-repetition/fsrs4anki)** ★4.1k — 现代化复习调度

## 25–40 岁 ｜ 成年初期

> 重点：职业纵深与 T 型扩展、刻意练习、从「会」到「强」。

此阶段时间碎片化，最忌「从头学一门新课」；要在真实项目里补洞。


对应十阶：→ [⑦ 精练](./stages/07-drill.md) · [⑧ 实战](./stages/08-apply.md)（干中学为主）

- **[Build Your Own X](https://github.com/codecrafters-io/build-your-own-x)** ★55.1万 — 从零手搓系统（干中学典范）
- **[K8s the Hard Way](https://github.com/kelseyhightower/kubernetes-the-hard-way)** ★5.0万 — 硬核方式掌握 Kubernetes
- **[System Design Primer](https://github.com/donnemartin/system-design-primer)** ★37.3万 — 系统设计入门
- **[nanoGPT](https://github.com/karpathy/nanoGPT)** ★6.4万 — 从零训练 GPT（能力边缘项目）
- **[LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch)** ★10.6万 — 从零构建大模型
- **[Zotero](https://github.com/zotero/zotero)** ★1.5万 — 文献与资料管理（研究型工作的地基）
- **[Coding Interview University](https://github.com/jwasham/coding-interview-university)** ★36.2万 — 转岗/晋升的系统复习

## 40–60 岁 ｜ 中年期

> 重点：整合、传承与输出 —— 把经验变成可复用资产。

此阶段的复利来自「讲清楚」：教学是最强维护（[⑨ 教学](./stages/09-teach.md)）。


对应十阶：→ [⑨ 教学](./stages/09-teach.md) · [⑩ 维护](./stages/10-maintain.md)

- **[Logseq](https://github.com/logseq/logseq)** ★4.5万 — 双链知识库（经验资产化）
- **[Obsidian Spaced Repetition](https://github.com/st3v3nmw/obsidian-spaced-repetition)** ★2.6k — 笔记内科学复习
- **[Quartz](https://github.com/jackyzha0/quartz)** ★1.3万 — 把笔记发布成网站
- **[Marp](https://github.com/marp-team/marp)** ★1.3万 — Markdown 做幻灯片（讲课）
- **[Slidev](https://github.com/slidevjs/slidev)** ★4.9万 — 面向开发者的幻灯片
- **[Quarto](https://github.com/quarto-dev/quarto-cli)** ★6.0k — 学术/技术出版系统
- **[MuseScore](https://github.com/musescore/MuseScore)** ★1.5万 — 开源制谱（兴趣即复利）

## 60+ 岁 ｜ 老年期

> 重点：认知维护、持续丰富的生活、乐学不辍。

诚实结论：认知训练对「近迁移」有限（[Salthouse 2009](<https://journals.sagepub.com/doi/full/10.1111/j.1539-6053.2009.01038.x>)）；但持续丰富的环境、社交与身体活动与更好的认知老化相关（[Hertzog et al. 2008](<https://journals.sagepub.com/doi/full/10.1111/j.1539-6053.2009.01034.x>)）。学新技能的真实价值在于「用进废退 + 生活意义」。


对应十阶：→ [⑩ 维护](./stages/10-maintain.md)

- **[KOReader](https://github.com/koreader/koreader)** ★3.0万 — 电纸书阅读（低负担长阅读）
- **[Calibre](https://github.com/kovidgoyal/calibre)** ★2.6万 — 电子书管理
- **[Lichess](https://github.com/lichess-org/lila)** ★1.9万 — 国际象棋（社交+认知活动）
- **[wger](https://github.com/wger-project/wger)** ★7.0k — 健身/活动记录（身体是认知的底座）
- **[Memos](https://github.com/usememos/memos)** ★6.3万 — 轻量记录，保持输出习惯
