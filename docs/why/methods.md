# 姐妹篇（下）· 学习方法全景：40+ 个方法，挂在阶段上才有意义

> 方法只有挂到「阶段 × 条件 × 剂量」上才成立——这正是[方法碎片化](fragmentation.md)的解药。本页按十阶时间线组织全部主要方法：每个方法给出做法、证据等级与关键文献。
> 系列 ①②③④ ｜ 姐妹篇：[上 · 理论框架全景](theories.md) ｜ **下 · 学习方法全景（本文）**

> 等级：A 强 / B 中 / C 弱-条件 / D 证伪（见[证据页](../evidence.md)）。「本项目整理」= 基于研究的设计经验，不冒充实证结论。

| 方法 | 做法（一句话） | 等级 | 文献 |
|---|---|---|---|

## 组合示例（把方法排成流水线）

```mermaid
flowchart LR
  A[目标+执行意图] --> B[建图/拆解]
  B --> C[编码：自我解释+生成]
  C --> D[检索：自由回忆+卡片]
  D --> E[间隔：FSRS 调度]
  E --> F[精练：刻意练习+反馈]
  F --> G[应用：真实项目]
  G --> H[教学：讲给别人]
  H --> I[维护：习惯+睡眠+运动]
  I --> D
```

三条常用路线：
- **应试型**：目标 → 建图 → 生成 → 卡片+FSRS → 变式题 → 模拟考（⑦）
- **技能型**：目标 → 拆解 → 示范淡出 → 干中学 → 反馈循环 → 公开输出
- **研究型**：建图 → 文献精读（自我解释）→ 无知清单 → 实验 → 写作传播（见[拓界篇](../stages/11-expand.md)）
