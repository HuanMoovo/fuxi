# 领域深潜 · 写作（Writing）

> 伏羲框架 · 万物皆可学 ｜ [系列首页](README.md) ｜ 领域深潜 8/10

写作同时暴露三件事：你知道什么、组织得怎么样、表达得清不清楚。好消息是：写作是所有输出技能里对教学干预最敏感的之一。

## 1. 证据地图

- **写作策略可教**：教学干预元分析（青少年与小学两个学段）都显示策略教学、范文模仿、句子合并等实践对写作质量有稳定增益（[C331][C332]）。
- **写作也是学习工具**：以写促学的元分析显示，不加评分压力的短写作任务能促进学科内容理解（[C333]）。
- **反馈是双刃剑**：反馈干预的平均效应为正，但约三分之一的案例反而降低表现——取决于反馈指向的层级（[C47]）。
- **写作能力按阶段发展**：从「知识讲述」到「知识转换」——高手边写边重构与组织知识，而不是把内容搬到纸上（[C334]）。

## 2. 关键方法与其证据

- **策略显式学**：把计划、起草、修订拆开练；模仿范文结构（[C331][C332]）。—— 证据：A/B
- **以写促学**：学科学习配短写任务（不评分、面向自己），让写作成为整合工具（[C333]）。—— 证据：B
- **反馈指向过程**：反馈要落在策略与内容层（「这段论证缺证据」），避免停留在泛泛评价；注意约 1/3 负效应风险（[C47]）。—— 证据：B
- **知识转换练习**：改写、压缩、重构已有材料，练习「边写边组织」（[C334]）。—— 证据：B
- **公开写作**：有真实读者的输出（社区、博客）制造反馈与责任。—— 证据：C（实践共识）

## 3. 十阶落点

| 阶段 | 写作场景的关键动作 |
|---|---|
| ① 立志 | 定「写给谁、写多少篇、什么质量」 |
| ② 建图 | 文体地图：目标读者的结构预期 + 范文样本库 |
| ③ 拆解 | 一篇文章拆：论点 → 结构 → 段落 → 句子 |
| ④ 编码 | 拆解优秀范文的骨架；积累句式与过渡 |
| ⑤ 检索 | 不看范文写提纲；写完再对照 |
| ⑥ 间隔 | 隔日修订（冷读者视角）；素材卡片间隔复现 |
| ⑦ 精练 | 段落级专项：一段只练一个技巧 |
| ⑧ 实战 | 每周一篇公开发布；拿真实反馈 |
| ⑨ 教学 | 帮别人改文章；说出修改理由 |
| ⑩ 维护 | 持续公开更新的栏目化写作 |
| ⑪ 拓界 | 写长文 / 书 / 论文；形成个人文体 |

## 4. 领域专属误区

- 「写作靠天赋」✗ —— 教学干预元分析显示写作技能可教（[C331]）。
- 「多读自然就会写」✗ —— 输入不等于输出技能；写作要单独练（[C334]）。
- 「反馈越多越好」✗ —— 约 1/3 的反馈干预反而降效；要针对过程与策略（[C47]）。
- 「初稿必须完美」✗ —— 修订本来就是写作的一半。
