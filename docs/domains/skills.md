# 领域深潜 · 技能学习（乐器 · 运动）

> 伏羲框架 · 万物皆可学 ｜ [系列首页](README.md) ｜ 领域深潜 4/10

乐器与运动是「动作技能」的两大代表：练的是身体，但组织练习的原则与认知学习既相通又有差异。本页收拢动作学习（motor learning）里最稳的几条结论。

## 1. 证据地图

- 动作技能的进步依赖反馈与变异：重复同一动作并不自动带来迁移（[C312][C313]）。
- 「注意力放在哪」会显著改变学习质量——这是近二十年动作学习最稳的发现之一（[C311]）。
- 睡眠是动作记忆的隐形教练：技能在睡后被巩固，熬夜练习会压掉一部分收益（[C316]）。

## 2. 关键方法与其证据

- **外部注意力焦点**：关注动作的效果（球落点、音色）比关注身体部位怎么动，学得更好（[C311]）。—— 证据：B
- **情境干扰（变式练习）**：交替或随机变换任务顺序，当下表现更差、保持与迁移更好；综述支持在多数场景使用（[C312][C313]）。—— 证据：B
- **心理演练**：不动机体的想象练习有稳定的中等效果，适合与实练组合（[C314]）。—— 证据：B
- **睡眠巩固**：训练后的睡眠显著提升技能保持；机制与整体睡眠管理见[学习的身体](body.md)（[C316]）。—— 证据：B
- **类比学习**：用「像甩鞭子」一类的比喻间接学习，在压力下失误更少，但证据等级有限（[C315]）。—— 证据：C
- **练习设计原则及其边界**：变式、反馈频率与任务复杂度共同决定迁移量（早期综述与边界讨论见 [C86]）。—— 证据：B
- **反馈频率（少即是多）**：降低每次尝试的结果反馈频率（带宽反馈、渐隐反馈），长期保持与迁移反而更好（[C324]）。—— 证据：B

## 3. 十阶落点

| 阶段 | 乐器 / 运动的关键动作 |
|---|---|
| ① 立志 | 定演出、比赛或曲目级别的可验证目标 |
| ② 建图 | 技术清单 → 曲目库 / 专项能力地图 |
| ③ 拆解 | 把乐句、技术动作拆到可短时重复的片段 |
| ④ 编码 | 慢速示范 + 视频对照；给动作配「一句话提示」 |
| ⑤ 检索 | 不看谱回忆乐句；闭眼复现动作序列 |
| ⑥ 间隔 | 训练日之间留间隔，而不是每天只练同一项 |
| ⑦ 精练 | 外部焦点（[C311]）+ 变式（[C312]）+ 录音录像反馈 |
| ⑧ 实战 | 演出、比赛模拟、录音棚环境 |
| ⑨ 教学 | 给新手带一节练习课；讲解迫使自己结构化 |
| ⑩ 维护 | 低频保持性练习 + 睡眠管理（[C316]） |
| ⑪ 拓界 | 改编、创作、编曲 / 编排 |

## 4. 领域专属误区

- 「练到不出错就停」✗ —— 缺变式的熟练在真实场景容易崩（[C313]）。
- 「注意力必须紧盯身体动作」✗ —— 外部焦点通常更优（[C311]）。
- 「熬夜加练 = 多赚一倍」✗ —— 会压掉睡眠巩固（[C316]）。
- 「心理演练是玄学」✗ —— 元分析支持中等效果（[C314]）。
