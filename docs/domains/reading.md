# 领域深潜 · 阅读（Reading）

> 伏羲框架 · 万物皆可学 ｜ [系列首页](README.md) ｜ 领域深潜 7/10

阅读是最古老的输入技能，也最容易被「读得多自然会」敷衍过去。本页把阅读科学里最稳的几条结论收拢成清单；词汇与二语的交叉证据见[语言学习](language.md)。

## 1. 证据地图

- **理解的大头是背景知识**：经典对照实验里，「知识多但阅读差」的读者记忆表现超过「阅读好但知识少」的读者——先有知识，才有理解（[C327]）。
- **阅读依赖解码自动化**：认词不占脑力，理解才有预算；自动化理论仍是解释阅读流畅度的基石（[C328]）。
- **策略干预有效但有限**：对高年级挣扎读者的阅读干预综合显示中小程度的稳定增益，效果取决于是否教到位（[C329]）。
- **阅读量与长期成就系统相关**：印刷暴露的元分析显示，读得多的孩子词汇、理解与学业成绩都更好（[C330]）。

## 2. 关键方法与其证据

- **先建背景知识**：读陌生领域前，先用概览、导览、讲解视频补 30 分钟背景，再进入细节（[C327]）。—— 证据：B
- **词汇与解码优先**：高频词族先拿下（[C294]），用间隔检索巩固（[C296]），让解码不占理解预算（[C328]）。—— 证据：A/B
- **策略显式学**：预测、提问、澄清、总结的多策略组合对难读材料有稳定帮助（[C329]）。—— 证据：B
- **读后检索**：合上材料白纸回忆主干，再回查缺口（检索效应 [C02]）。—— 证据：A
- **读量即维护**：把阅读做成日常低频维护而不是突击任务；长期积累本身就是方法（[C330]）。—— 证据：B

## 3. 十阶落点

| 阶段 | 阅读场景的关键动作 |
|---|---|
| ① 立志 | 定「读懂什么类型 / 什么难度」而不是「多读书」 |
| ② 建图 | 领域书单按难度与依赖排序；先广后深 |
| ③ 拆解 | 长文拆章节；难段拆「一句一意」 |
| ④ 编码 | 批注 + 图示重构；一句话概括每节 |
| ⑤ 检索 | 读后白纸回忆；不带书回答「这章讲了什么」 |
| ⑥ 间隔 | 关键内容进卡片；隔几日再回来 |
| ⑦ 精练 | 难句子精读：语法拆解 + 复述 |
| ⑧ 实战 | 用读到的内容解决问题、写笔记、做推导 |
| ⑨ 教学 | 把一章讲给别人；讲不清就回去补 |
| ⑩ 维护 | 日常阅读清单（新闻 / 专业 / 兴趣）低频滚动 |
| ⑪ 拓界 | 从读者变作者：综述、翻译、评论 |

## 4. 领域专属误区

- 「读得快 = 读得好」✗ —— 速度不能以理解为代价（速读宣称与阅读科学不符，见[误区库](../myths.md)）。
- 「划线和重读很用功」✗ —— 低效技术；读后检索才是硬通货（[C02]）。
- 「技巧包治」✗ —— 背景知识不足时，策略收益有限（[C327][C329]）。
- 「读完就完」✗ —— 无检索、无输出，遗忘曲线会收回大部分内容。
