# 领域深潜 · 考试与应试

> 伏羲框架 · 万物皆可学 ｜ [系列首页](README.md) ｜ 领域深潜 5/10

考试是「学习」的高压版本：时间封顶、目标外置、结果一次性结算。它不改变学习规律，只是把执行密度拉满。本页是[路线与领域](../paths.md)「冲刺轨」的证据版：考前每一周该做什么、为什么。

## 1. 证据地图

- **检索练习是收益最高的方法**：practice testing 的大规模元分析覆盖数百项实验，对各类学科与年龄段的考试场景都有稳定增益（[C03]）；测试效应本身在延迟重测上远超重读（[C02][C76]）。
- **间隔决定结算时的保持**：分布复习优于集中突击；最佳间隔约为目标保持期的 10–20%（[C04]）。
- **焦虑有真实成本，也有可用干预**：数学焦虑与成绩负相关（[C308]）；考前表达性写作能提升考场表现（[C310]）。
- **睡眠是考场能力的最后一环**：记忆巩固发生在睡眠中，考前通宵通常得不偿失（[C317]）。

## 2. 关键方法与其证据

- **模考即检索**：把复习做成考试形式——限时、闭卷、混合题型；练习测试元分析支持其稳定增益（[C03]）。—— 证据：A
- **检索优先于重读**：重读制造「看懂了」的流畅错觉；考试结算的是延迟保持（[C02][C76]）。—— 证据：A
- **间隔排程到考期**：按目标保持期的 10–20% 布置复习间隔（[C04]）；考前 1–2 天做全真模拟。—— 证据：A/B
- **错题闭环**：错题不抄写，而是「找错因 → 变式重做 → 一周后复测」，处理方式与精练阶段一致（见[第 7 阶 · 精练](../stages/07-drill.md)）。—— 证据：B
- **焦虑干预**：考前 10 分钟表达性写作（写下担忧）在课堂实验中提升了考试成绩（[C310]）；长期靠补缺与模拟考降敏（[C308]）。—— 证据：B
- **考前睡眠**：把最后冲刺压在考前通宵通常得不偿失——巩固发生在睡眠里（[C317]）。—— 证据：A/B

## 3. 十阶落点

| 阶段 | 应试场景的关键动作 |
|---|---|
| ① 立志 | 从考纲倒推目标分数与能力清单 |
| ② 建图 | 考纲 → 知识树；标出分值高、自己弱的节点 |
| ③ 拆解 | 按题型拆「识别信号 → 套路 → 易错点」 |
| ④ 编码 | 错题与关键公式进卡片；用自己的话复述考点 |
| ⑤ 检索 | 模考、默写、闭卷自测；对答案前先写满 |
| ⑥ 间隔 | FSRS 排程复习卡与错题；按考期倒推间隔 |
| ⑦ 精练 | 弱项专项：限时小卷 + 即时反馈 |
| ⑧ 实战 | 全真模拟：时间、环境、文具、流程全仿真 |
| ⑨ 教学 | 给同学讲题；讲不清的题就是没掌握 |
| ⑩ 维护 | 考前一周：睡眠、轻量复习、不再开新战场 |
| ⑪ 拓界 | 考后把备考能力迁移到真实任务（[paths.md](../paths.md) 换乘规则） |

## 4. 领域专属误区

- 「考前一周才开始」✗ —— 间隔收益需要提前量（[C04]）。
- 「刷题 = 对答案」✗ —— 不打错因标签的刷题几乎无效；错题系统才是资产。
- 「考前通宵再冲一把」✗ —— 压掉的是巩固与第二天的编码质量（[C317]）。
- 「焦虑就是心理素质差」✗ —— 有真实认知代价（[C308]），也有实证干预（[C310]）。
