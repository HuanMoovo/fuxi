# 领域深潜 · 语言学习（第二语言）

> 伏羲框架 · 万物皆可学 ｜ [系列首页](README.md) ｜ 领域深潜 1/5

语言学习是「万物皆可学」的原型场景，也是量化证据最密集的领域之一：词汇量、间隔、辨音训练，每个环节都有可核验的研究。本页只讲语言领域特有的证据与落差；通用方法见[方法全景](../why/methods.md)。

## 1. 证据地图：先看三个数字

- **词汇量是第一约束**：要理解书面文本约 98%，需要约 8000–9000 词族；口语门槛低得多（约 2000 词族覆盖日常口语的大部分）（[C294]）。
- **一个词要见很多面**：生词的掌握依赖重复接触，且检索式接触的收益远高于反复阅读（[C295]）。
- **间隔效应在二语成立**：间隔练习对第二语言学习的元分析显示，间隔组在延迟测验上稳定优于集中组（[C296]）。

## 2. 关键方法与其证据

- **间隔 + 产出式检索**：二语词汇与语法形式的间隔练习有元分析支持（[C296]）；卡片要考产出（先说出来、写出来，再翻面），只做识别式选择收益低（[C295]）。—— 证据：A（针对词汇与语法形式）
- **高频优先**：先吃前 2000 词族（口语覆盖的主力），再按频率向 5000–9000 爬坡；按频率学比按字母表少走弯路（[C294]）。—— 证据：B
- **大量输入（泛读）**：泛读元分析显示整体收益为正、量级偏小到中等，集中在阅读与词汇；对口语、写作的迁移证据弱（[C297]）。—— 证据：B
- **辨音训练（HVPT）**：高变异听辨训练可以让成人在非母语音位（如 /r/–/l/）上显著进步；1991 年的首个系统报告是这条路线的事实起点（[C298]）。—— 证据：B
- **显性发音教学**：叙述性综述显示效果稳定但中等以下；收益主要在「可理解性」，而非「口音像母语者」（[C299]）。—— 证据：B/C
- **纯输入自动习得**：只靠看剧、听播客「自然学会」的说法缺乏直接证据；理解 + 检索 + 输出反馈的组合才稳（[C295][C296]）。—— 证据：C（对「无需刻意练习」的否定）

## 3. 十阶落点

| 阶段 | 语言领域的关键动作 |
|---|---|
| ① 立志 | 定场景目标（考试 / 口语 / 阅读），而不是「学会英语」 |
| ② 建图 | 音系 → 核心词汇 → 语法骨架 → 场景表达，四层地图 |
| ③ 拆解 | 词族、音位对、句型块（chunks）拆到 15–60 分钟可练 |
| ④ 编码 | 例句 + 情境画面 + 发音锚点；把词放进「你会说出口的句子」 |
| ⑤ 检索 | 产出式卡片：先想后看；阅读后白纸回忆主干 |
| ⑥ 间隔 | 按 [C296] 的间隔排程复习词汇与语法 |
| ⑦ 精练 | 辨音训练（[C298]）、跟读录音对比、写作纠错 |
| ⑧ 实战 | 真实对话与写作，拿真人反馈（或带护栏的 AI） |
| ⑨ 教学 | 语言交换里互相当老师，把语法讲给别人听 |
| ⑩ 维护 | 把新闻 / 剧集 / 播客变成低频维护，而不是主要输入 |
| ⑪ 拓界 | 用目标语做研究、写长文、翻译作品 |

## 4. 领域专属误区

- 「看剧就能自动学会」✗ —— 需要理解 + 足量 + 检索；泛读自身的增益有限（[C297]）。
- 「先把语法学完再开口」✗ —— 输出第一周就可以开始，语法在检索与纠错中更稳。
- 「口音必须像母语者」✗ —— 证据指向的教学目标是「可理解性」（[C299]）。
- 「单词 App 打卡就算学了」✗ —— 识别式选择的深度远低于产出式检索（[C295][C296]）。
