# 领域深潜 · 医学与临床学习（Medicine & Clinical Skills）

> 伏羲框架 · 万物皆可学 ｜ [系列首页](README.md) ｜ 领域深潜 10/10

医学是「高后果学习」的代表：知识量最大、时效要求最严、失误代价最高。也正因如此，学习科学最可靠的方法都最早在医学教育落地验证——本页就是它们的清单。

## 1. 证据地图

- **检索优于重读在医学教育成立**：医学生的测试效应实验显示，测试组的延迟保持显著优于重读组（[C337]）。
- **仿真训练有中到大效应**：技术增强仿真的系统综述与元分析显示，对知识、技能与临床行为的多层增益（[C338]）。
- **刻意练习是专家能力的主通道**：医学领域专家发展研究支持「明确目标 + 即时反馈 + 重复修正」的结构（[C339]）。

## 2. 关键方法与其证据

- **检索式复习贯穿全程**：课堂后自测、病例归档后回顾自问；把「看过病例」变成「能复述处置逻辑」（[C337]）。—— 证据：A/B
- **仿真 + 刻意练习**：技能先分解练、再整合并带即时反馈；仿真能替代部分床旁练习，但不能完全替代（[C338][C339]）。—— 证据：A/B
- **错误复盘制度**：病例讨论定位「系统与流程原因」而不是止于个人归咎——复盘要产出可执行的改进（[C339]）。—— 证据：B
- **间隔串联跨科知识**：用间隔复习卡把内外妇儿的知识点串联（[C04]）。—— 证据：B

## 3. 十阶落点

| 阶段 | 临床场景的关键动作 |
|---|---|
| ① 立志 | 按考试 / 临床能力双线定目标 |
| ② 建图 | 系统 → 器官 → 疾病 → 处置的层级地图 |
| ③ 拆解 | 每个病种拆：识别 → 鉴别 → 处置 → 随访 |
| ④ 编码 | 临床推理链 + 典型病例图 |
| ⑤ 检索 | 自测题、盲写处置流程、病例闭卷复述（[C337]） |
| ⑥ 间隔 | 跨科知识卡片按 FSRS 调度（[C04]） |
| ⑦ 精练 | 仿真训练带反馈；技能分解到可重复单元（[C338]） |
| ⑧ 实战 | 真实轮转；每次新病例按「检索-复盘」闭环 |
| ⑨ 教学 | 带教与病例汇报；讲不清的鉴别诊断回去补 |
| ⑩ 维护 | 专科知识低频维护；指南更新追踪 |
| ⑪ 拓界 | 病例报告、临床研究、质量改进项目 |

## 4. 领域专属误区

- 「看得多就会」✗ —— 观察不产生技能，练习与反馈才产生（[C338][C339]）。
- 「经验年限 = 能力」✗ —— 专家能力靠刻意练习积累，而非年限自动叠加（[C339]）。
- 「仿真 = 玩」✗ —— 结构良好的仿真有元分析级增益（[C338]）。
- 「考试式复习只为应试」✗ —— 检索练习正是保持临床知识最稳的方式（[C337]）。
