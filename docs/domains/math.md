# 领域深潜 · 数学学习

> 伏羲框架 · 万物皆可学 ｜ [系列首页](README.md) ｜ 领域深潜 3/6

数学是「程序性知识」与「概念性知识」双线交织的领域：算法要练熟，概念要理解，而两者之间的桥——迁移——恰恰最难。本页收拢数学领域最硬的几条证据。

## 1. 证据地图

- **门槛知识存在**：分数知识（大小比较、运算意义）是代数学习的关键预测变量；早期漏洞会在代数里放大（[C309]）。
- **数学焦虑是真实变量**：它与成绩呈稳定负相关（元分析），并占用工作记忆（[C308]）。
- **练习的排法有讲究**：同样数量的题，交错排（不同题型混排）比块状排（同类型连做）在延迟测验上显著更好（[C306][C07]）。

## 2. 关键方法与其证据

- **交错练习**：把不同类型题混排；原始研究（[C306]）与课堂随机对照试验（[C07]）都支持延迟保持优势。—— 证据：A
- **示范题 + 淡出**：新手先学范例、再在引导下解题、最后独立解；对图式构建显著优于纯做题（[C307]）。—— 证据：A/B
- **检索先于重读**：合上书先回忆公式与解法主线，再对照补缺（通用证据见[方法全景](../why/methods.md)）。—— 证据：A
- **对付数学焦虑**：考前短时表达性写作（写下担忧）在课堂实验中提升了考试表现（[C310]）；长期路线是补知识漏洞——焦虑多源于真实的能力缺口（[C308]）。—— 证据：B
- **门槛知识优先**：分数不过关先补分数，而不是硬推进新章节（[C309]）。—— 证据：B

## 3. 十阶落点

| 阶段 | 数学领域的关键动作 |
|---|---|
| ① 立志 | 目标绑定具体能力（「独立做出某类题」），附时间与题量预算 |
| ② 建图 | 章节依赖图：没过关的门槛节点标出来 |
| ③ 拆解 | 每类题拆成「识别信号 → 选择工具 → 执行步骤」三段 |
| ④ 编码 | 示范题 + 子步骤标注；用「一句话讲清这题在考什么」自检 |
| ⑤ 检索 | 白纸回忆解法主线；公式从推导里回忆而不是硬背 |
| ⑥ 间隔 | 错题与典型题进间隔系统，按题型交错出题（[C306][C07]） |
| ⑦ 精练 | 限时训练要谨慎（焦虑会放大，[C308]）；先正确率后速度 |
| ⑧ 实战 | 真题卷、建模题、讲题给别人听 |
| ⑨ 教学 | 讲题是最强检索：每一步都讲出「为什么」 |
| ⑩ 维护 | 低频重做代表性题目，防止生疏 |
| ⑪ 拓界 | 从做题走向提出问题、读原始论文 |

## 4. 领域专属误区

- 「题海 = 每天同一种题型刷一百道」✗ —— 块状刷题缺交错，延迟保持差（[C306][C07]）。
- 「看懂了 = 会做了」✗ —— 觉得懂是流畅错觉，白纸重做才算数。
- 「做题速度代表数学能力」✗ —— 速度受焦虑与熟练度双重影响；先正确率后速度（[C308]）。
- 「数学焦虑只能硬扛」✗ —— 表达性写作等干预有效（[C310]），但根治靠补缺。
