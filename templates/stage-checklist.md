# 《十阶过关清单》

> 用法：每阶过关后再勾选，全部勾上再进入下一阶；标准可精简，不可跳过。
> 总原则：先建图再填肉、先检索再重复、先做真事再谈精通。

## 第 1 阶 · 立志（Orient）

- [ ] 能一句话说清「为什么学」
- [ ] 三个结果写好，且可被别人检验（含完成标准）
- [ ] 有「每周什么时候学」的具体时段
- [ ] 写下「状态差时怎么保底」
- [ ] 《学习契约》已签署，放在看得见的地方

## 第 2 阶 · 建图（Map）

- [ ] 一页领域地图完成（知识树或概念图）
- [ ] 能在 60 秒内讲清地图主干
- [ ] 指出 3 个门槛概念（threshold concepts）
- [ ] 地图上标出「已知／半懂／未知」三色
- [ ] 候选素材源清单列好

## 第 3 阶 · 拆解（Decompose）

- [ ] 原子清单完成：每个原子 = 一次能练或能考的最小单元
- [ ] 依赖顺序已排序（先决条件先学）
- [ ] 每个原子都对应一个 15–30 分钟的练习动作
- [ ] 能对任一原子说出「学它之前需要什么」

## 第 4 阶 · 编码（Encode）

- [ ] 一页《最简解释》完成（自己的话 + 例子 + 反例）
- [ ] 不看材料，用 5 句话 + 1 个例子讲清任一原子
- [ ] 能说出任一原子与已知知识的 2 条链接
- [ ] 第一批卡片完成（符合《卡片制作规则》）

## 第 5 阶 · 检索（Retrieve）

- [ ] 空白纸回忆：任一主链主题 ≥ 80% 要点
- [ ] 延迟 48 小时后仍 ≥ 70%
- [ ] 错误卡片有「为什么错」备注
- [ ] 自出题、低风险测验成为日常

## 第 6 阶 · 间隔（Space）

- [ ] FSRS 优化器跑通，并用了个人参数
- [ ] 30 天留存统计在目标线附近
- [ ] 每周交错测验有记录
- [ ] 复习量受控：不欠债、不为算法打工

## 第 7 阶 · 精练（Drill）

- [ ] 错误日志连续 2 周有记录
- [ ] 每条记录都有「修正动作 → 复测」闭环
- [ ] 靶子子技能有通过标准（如 90% 正确率）
- [ ] 练习稳定在能力边缘，有即时反馈与修正

## 第 8 阶 · 实战（Apply）

- [ ] 有一个外人可点开的成果（作品或链接）
- [ ] 收到过至少 1 次真实反馈，并据此迭代
- [ ] 能从成果反推「下一个要补的知识点」
- [ ] 「做 → 问题 → 学 → 补」成为默认模式

## 第 9 阶 · 教学（Teach）

- [ ] 讲给真人（或 AI 扮演的小白）10 分钟，对方能复述主干
- [ ] 在两个新情境里用同一知识成功解题（迁移测试）
- [ ] 有一份公开输出（文章、视频或答疑）

## 第 10 阶 · 维护（Maintain）

- [ ] 3 个月后随机抽 5 张旧卡能过
- [ ] 有新输出（答疑、文章或作品更新）
- [ ] 周检视与季度回顾在运转
- [ ] 下一个学习目标已启动（螺旋重启，复用十阶）

---

> 十阶走完不是终点：维护是低频长跑；下一轮螺旋从第 1 阶重新开始。
